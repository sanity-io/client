'@sanity/client': minor
---

`client.fetch(query, params)` now infers its result and params types from a query branded with `__groqResult` and `__groqParams`, such as the default export of a `.groq` file imported through `@sanity-labs/groq-content-mapper`, with no generic argument and no `SanityQueries` entry. `ClientReturn` reads the result brand before the registry lookup, and the new `ClientParams` type reads the params brand; `listen` checks params the same way. Reading the brand is experimental. Plain strings, `defineQuery`, explicit generics and `SanityQueries` registrations resolve as before.
